## [0.1.0] - 2026-08-09

### Added

- Strict, ESM-only TypeScript client for pairing with existing T3 Code servers.
- Authenticated same-origin HTTP requests and ticketed WebSocket connections.
- Pairing URL, hosted pairing URL, and endpoint plus pairing-code inputs.
- Persistent credential stores with an owner-only POSIX filesystem implementation.
- Typed project, thread, history, and turn actions over T3 Code's HTTP API.
- Reproducible Docker integration fixture with OpenCode and OpenRouter configuration.
